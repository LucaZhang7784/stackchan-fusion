# Fusion Gateway 守护 + 系统托盘（2026-08-01）

## 组件

| 文件 | 作用 |
|---|---|
| `run_gateway.ps1` | 启动网关（幂等：已监听 8010 则跳过） |
| `watchdog_gateway.ps1` | 手动兜底检查脚本（不再注册为定时任务） |
| `fusion_tray.ps1` | 系统托盘状态工具（WinForms，无第三方依赖） |
| `install_autostart.ps1` | 一键注册三个计划任务 |
| `run_gateway_hidden.vbs` / `fusion_tray_hidden.vbs` | wscript 隐藏启动器（任务用, 杜绝弹窗） |

## 托盘功能（2026-08-01 增强版）

- 每 5 秒轮询三个状态，图标颜色反映整体健康度：
  - 绿色：网关 + MCP Toolkit + 机器人 bridge 全部正常
  - 橙色：网关正常但 MCP 或机器人链路异常
  - 红色：网关离线
- 鼠标悬停显示：网关在线/离线、MCP 状态、机器人状态、工具数
- 双击图标：查看状态详情
- 右键菜单：
  - 查看状态详情
  - 重启网关（停旧进程 → 启动新进程）
  - 退出托盘（仅退出托盘，不影响网关）
- 状态变化时弹出气泡提醒（恢复 / 离线 / 部分异常）
- **内置守护**：检测到网关离线自动静默拉起（30 秒防抖），不弹窗口

## 状态判断口径

- Gateway：`GET http://127.0.0.1:8010/healthz` + Bearer token（config.json 的 auth_token）
- MCP：`docker mcp profile show stackchan` 是否包含 fusion-gateway
- Robot：xiaozhi-mcp 的 `mcp_pipe.py` / `server.py` 进程是否存活 + `bridge.err` 心跳写入时间 ≤ 3 分钟

## 已注册的计划任务

| 任务名 | 触发 | 内容 |
|---|---|---|
| `StackChan-FusionGateway` | 登录时 | wscript.exe 隐藏启动网关（无控制台窗口） |
| `StackChan-FusionTray` | 登录时 | wscript.exe 隐藏启动托盘（内置守护） |
| `StackChan-FunnelProxyWatchdog` | 登录时 + 每 5 分钟 | wscript.exe 隐藏自愈备用路由 funnel 代理 |

## 验证结果（2026-08-01 已实测）

- 手动 kill 网关 → 托盘在 ~10-15 秒内自动拉起，healthz 恢复 ok，MCP 11 工具可见
- 托盘进程启动并持续运行，三个状态源均返回正常
- 已删除 `StackChan-FusionGatewayWatchdog` 定时任务（弹窗根源），守护并入托盘
- 2026-08-03 修复弹窗复发: 计划任务直接跑 powershell 时, 即使带 `-WindowStyle Hidden`
  仍会闪一下控制台窗口（每 5 分钟的 funnel / promlight watchdog 均是此类）;
  全部改由 `wscript.exe` + VBS 隐藏启动器注册, wscript 是 GUI 子系统无控制台,
  从物理上杜绝闪窗。install_autostart.ps1 已按新方式注册。

## 手动操作

```powershell
# 重装全部任务 + 立即启动托盘（需管理员权限）
powershell -NoProfile -ExecutionPolicy Bypass -File install_autostart.ps1

# 只跑一次 watchdog
powershell -NoProfile -ExecutionPolicy Bypass -File watchdog_gateway.ps1

# 手动启动托盘
powershell -NoProfile -ExecutionPolicy Bypass -File fusion_tray.ps1
```
### 图标设计

32x32 圆角渐变图标（健康色背景: 绿=全部正常 / 橙=部分异常 / 红=网关离线），
内部三个白色状态点: 上左=网关, 上右=MCP, 下=机器人（白=在线, 半透明=离线）。

### 右键子菜单实时状态

| 菜单 | 内容 |
|---|---|
| 总状态头 | 整体健康度 + 当前时间 |
| Gateway | PID / 工具数 / 队列消息数 |
| MCP Toolkit | profile 状态 / 已连接客户端 |
| 机器人链路 | bridge 进程数 / 心跳时间 / 最近接收的工具调用 |
| 消息与待办 | 待推送队列数 / agent 事件数 / 待确认问题数 / 最近事件摘要 |

悬停 Tooltip 精简版: 三路状态 + 队列 + 待确认。
双击图标或「查看状态详情」弹完整详情窗。
