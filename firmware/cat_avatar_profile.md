# Cat 面部配置（v08.32）

`avatar-profiles/Cat.json` 是 320 x 240 CoreS3 屏幕的 Cat 面部参数来源：橙金色椭圆眼、
Omega 嘴型、眨眼、视线微动和呼吸节奏。当前固件的头像由运行时 LVGL 绘制，而不是由
`assets.bin` 中的静态图片驱动，因此更换该面部应在 CoreS3 板级头像绘制代码中应用这组参数，
然后重新构建应用。

## 参数映射

- 主色：`#FFC533`；背景：黑色。
- 双眼中心：左 `(228, 98)`、右 `(92, 98)`；各为 `30 x 54` 椭圆。
- 嘴中心：`(160, 150)`；静止范围 `52 x 10`，说话时可扩到 `84 x 56`。
- 动画：4.5 秒一次、120 ms 的眨眼；2 秒一次、幅度 0.55 的视线微动；3 秒呼吸周期、深度 0.6。
- 表情：`happy` 使用下眼睑 0.5；`angry` / `sad` 使用相反方向的上眼睑；`doubt` 使用不对称眼睑；`sleepy` 使用 0.65 眼睑覆盖。

## 刷写边界

只刷应用分区 `0x410000`，保留已有 Wi-Fi 凭据、配网状态和静态资源分区。刷写前确认串口为
StackChan 的 CoreS3 设备；不要对其他 ESP32 设备操作。
