# 🤖 桌面机器人 × 本地 AI Agent：把「阿松」变成你的语音中控台

> 给电脑和机器人小白的入门介绍 · 项目全开源 · 自建链路

---

## 这是什么？

一个 **M5Stack CoreS3 桌面机器人**(StackChan), 接上你自己电脑里的
**4 个 AI 编程助手**(Codex / Claude / Antigravity / PI), 变成一台
**语音中控台**:

🗣️ 你说: "让 codex 总结一下这个项目"
🤖 它答: "正在执行, 稍后问结果" → Codex 在电脑上真的开始干活
🔔 干完: 机器人**主动开口**播报结果摘要(不用你盯屏幕)
❓ 要确认: 机器人把问题念给你, 你用语音回答"可以/不行", 回传给 agent

还能: 问时间/天气、点头摇头、换表情、调音量、拍照识物、播报待办队列。

---

## 已实现 ✅

- 双击 / 喊「阿松」/ 摸头 三种方式唤醒
- 语音对话(普通话/粤语音色), 几秒应答
- **主动播报**: agent 任务完成/需要确认 → 机器人立即开口
- 语音指挥 4 个 agent, 结果回流到机器人
- 局域网有 AP 隔离也能用(通过 Tailscale Funnel 公网穿透)
- 全部数据/配置在本机, 不依赖任何智能体云

## 还没实现 / 注意 ⚠️

- 电脑必须开机且网络通畅(机器人本身是"瘦客户端")
- 公网中继偶发抖动 → 唤醒/推送偶发变慢(不常发生)
- 识别率取决于所用 ASR 服务, 嘈杂环境偶发听错
- 需要一点动手能力: Docker、Tailscale、刷固件(有脚本)
- 设备端回声消除不可用, 播报时请用双击打断插话
